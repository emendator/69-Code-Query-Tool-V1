### 步骤 1.2 — CRUD 操作

**文件**: `backend/crud.py`

- [x] `get_products(page, page_size, search)` — 分页查询
- [x] `get_product_by_code(code)` — 单码查询

## 附录：关键决策记录

| 序号 | 决策 | 备选方案 | 选择理由 |
| ------ | ------ | ---------- | ---------- |
| 1 | 使用 SQLite 而非 MySQL/PostgreSQL | 需要安装数据库服务 | 单机工具，零配置 |
| 2 | 使用 Ant Design 而非其他 UI 库 | Element, MUI | 成熟的表格+表单组件 |
| 3 | 模糊匹配用 difflib 而非 fuzzywuzzy | fuzzywuzzy 需额外安装 | 内置库，零依赖 |
| 4 | 69 码用 TEXT 而非 INTEGER | 可能包含前导零 | 保证数据完整性 |
| 5 | 列配置存后端而非 localStorage | 多设备共享 | 统一管理，避免丢失 |
