# 69码查询器 — 需求分析文档

> 版本: v1.0  
> 日期: 2026-07-30  
> 状态: 初稿

---

## 1. 项目背景

用户需要一款**69码查询工具**，能够将多个不同来源的表格（Excel/CSV）中的产品数据整合入库，随后通过 69 码（EAN-13 中国商品条码，以 `69` 开头）快速检索对应的产品信息，并支持批量查询、结果导出、数据管理等功能。

---

## 2. 用户角色

| 角色 | 描述 |
|------|------|
| **普通用户** | 上传表格、查询 69 码、导出结果 |
| **管理员** | 维护数据库（增删改查）、管理列配置、管理语义库、去重 |

---

## 3. 功能需求

### 3.1 核心功能：69 码查询

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-01 | **单码查询** | P0 | 输入单个 69 码，返回该行完整数据 |
| F-02 | **批量查询** | P0 | 用户以换行分隔输入多个 69 码，系统逐条匹配并返回结果集 |
| F-03 | **结果导出** | P1 | 查询结果可选择性导出为 Excel/CSV，用户可勾选需要导出的列和行 |
| F-04 | **空结果提示** | P1 | 未匹配到数据的 69 码，在结果中标记为"未找到"，不影响其他结果 |

### 3.2 列配置管理

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-05 | **列显示配置** | P1 | 用户可自由配置查询结果表和数据库管理表中各列的显示/隐藏 |
| F-06 | **列顺序调整** | P1 | 支持拖拽或上下箭头调整列的位置顺序 |
| F-07 | **列重命名** | P1 | 用户可为每列自定义显示名称（不影响数据库实际字段名） |
| F-08 | **列宽度设置** | P2 | 用户可调整每列的显示宽度，配置持久化到本地存储或后端 |

### 3.3 数据管理

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-09 | **数据库浏览** | P0 | 以表格形式展示数据库中所有记录，含自增序号列且升序排列 |
| F-10 | **新增记录** | P0 | 手动添加单条数据记录 |
| F-11 | **编辑记录** | P0 | 双击或点击编辑按钮修改已有记录 |
| F-12 | **删除记录** | P0 | 单条或批量删除记录 |
| F-13 | **高级搜索** | P1 | 支持按任意列（型号、品名、69码等）搜索数据库 |
| F-14 | **数据导入** | P0 | 上传 Excel/CSV 文件，自动匹配列并导入数据库 |
| F-15 | **数据导出** | P1 | 将数据库全部或筛选后数据导出为 Excel/CSV |

### 3.4 智能列匹配

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-16 | **自动列匹配** | P0 | 导入时后端自动识别表格中的"型号"类、"品名"类、"69码"类列 |
| F-17 | **模糊匹配** | P1 | 支持近似列名匹配（如"产品型号"→"型号"） |
| F-18 | **语义匹配** | P1 | 基于语义库进行语义层面的匹配（如"产品编号"→"69码"） |
| F-19 | **匹配确认交互** | P1 | 前端弹窗展示列匹配结果，用户可修改，确认后导入 |
| F-20 | **语义库扩充** | P1 | 用户确认匹配后可选择"加入语义库"，后续相同列名自动匹配 |

### 3.5 数据来源与备注

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-21 | **数据来源列** | P0 | 每条记录自动记录来源表格的文件名（不含路径） |
| F-22 | **备注列** | P1 | 备注不由导入自动填充，用户在数据管理页手动填写 |
| F-23 | **导入时间** | P0 | 每条记录自动记录导入时间戳 |

### 3.6 去重管理

| ID | 需求 | 优先级 | 说明 |
| ---- | ------ | -------- | ------ |
| F-24 | **重复检测** | P0 | 以 69 码为唯一标识，检测数据库中的重复记录 |
| F-25 | **重复项高亮** | P1 | 在前端数据管理页中，重复记录以特殊颜色/标记突出显示 |
| F-26 | **一键去重** | P1 | 提供"一键去重"按钮，保留最早导入的记录，删除后续重复项 |

---

## 4. 非功能需求

| ID | 需求 | 说明 |
| ---- | ------ | ------ |
| N-01 | **响应时间** | 单码查询 < 1s，批量查询（100 条）< 3s |
| N-02 | **并发支持** | 单机工具，支持 1-5 人同时使用 |
| N-03 | **数据安全** | 本地 SQLite 存储，不联网，无数据泄露风险 |
| N-04 | **兼容性** | 支持 .xlsx / .xls / .csv 格式导入 |
| N-05 | **编码处理** | 自动处理 UTF-8 / GBK / GB2312 编码的 CSV 文件 |
| N-06 | **可扩展性** | 数据库结构支持后续增加自定义列 |

---

## 5. 数据字段说明

| 字段 | 类型 | 必填 | 来源 | 说明 |
| ------ | ------ | ------ | ------ | ------ |
| 序号 | INTEGER (自增) | 自动 | 系统 | 主键，升序 |
| 型号 | TEXT | 否 | 导入匹配 | 产品型号/规格 |
| 品名 | TEXT | 否 | 导入匹配 | 产品名称/描述 |
| 69码 | TEXT | **是** | 导入匹配 | 13位条码（去重标准） |
| 数据来源 | TEXT | 自动 | 系统 | 源文件名 |
| 备注 | TEXT | 否 | 用户手动 | 用户自定义备注 |
| 导入时间 | DATETIME | 自动 | 系统 | ISO 格式时间戳 |

## 7. 界面原型概述

### 7.1 主界面布局

```
┌─────────────────────────────────────────────────────┐
│  69码查询器                  [设置] [关于]           │
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  📌 导航 │          📋 主内容区                      │
│          │                                          │
│  🔍 查询 │  根据当前选中的导航项切换内容              │
│          │                                          │
│  📊 数据 │  - 查询页: 输入框 + 结果表格              │
│   管理   │  - 数据管理: 数据库表格 + 操作按钮        │
│          │  - 配置页: 列配置面板                     │
│  ⚙ 配置 │                                          │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

### 7.2 核心交互流程

```
上传表格 → 后端解析 → 列匹配(模糊+语义) → 前端确认 → 导入数据库 → 完成
                                                                    
查询 69码 → 数据库检索 → 结果展示 → 选择性导出 → 完成
                                                                    
数据管理 → 浏览/搜索 → 增删改 → 去重 → 导出/导入 → 完成
```
