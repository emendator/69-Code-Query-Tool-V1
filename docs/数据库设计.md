## 1. 数据表总览

| 表名 | 用途 |
| ------ | ------ |
| `products` | 核心产品数据表 |

## 2. `products` — 产品数据表

### DDL

```sql
CREATE TABLE IF NOT EXISTS products (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    model       TEXT    NOT NULL DEFAULT '',
    name        TEXT    NOT NULL DEFAULT '',
    code        TEXT    NOT NULL DEFAULT '',
    source      TEXT    NOT NULL DEFAULT '',
    remark      TEXT    NOT NULL DEFAULT '',
    created_at  TEXT    NOT NULL DEFAULT (datetime('now', 'localtime')),
    updated_at  TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
);

CREATE UNIQUE INDEX idx_products_code ON products(code);
CREATE INDEX idx_products_model ON products(model);
CREATE INDEX idx_products_name ON products(name);
```

### 字段说明

| 字段 | 类型 | 约束 | 说明 |
| ------ | ------ | ------ | ------ |
| `id` | INTEGER | PK, AUTOINCREMENT | 自增序号，升序排列 |
| `model` | TEXT | NOT NULL, DEFAULT '' | 产品型号，导入时自动匹配 |
| `name` | TEXT | NOT NULL, DEFAULT '' | 产品品名/名称，导入时自动匹配 |
| `code` | TEXT | NOT NULL, DEFAULT '' | **69码**，唯一索引，去重依据 |
| `source` | TEXT | NOT NULL, DEFAULT '' | 数据来源=源文件名，导入时自动填充 |
| `remark` | TEXT | NOT NULL, DEFAULT '' | 备注，用户手动填写 |
| `created_at` | TEXT | NOT NULL | 导入时间，自动生成 |
| `updated_at` | TEXT | NOT NULL | 更新时间，自动更新 |

### 索引策略

- `code` 唯一索引: 保证 69 码唯一性，加速查询
- `model` / `name` 普通索引: 加速搜索

## 3. `semantic_mappings` — 语义库表

### DDL

```sql
CREATE TABLE IF NOT EXISTS semantic_mappings (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    source_column   TEXT    NOT NULL,
    target_field    TEXT    NOT NULL CHECK(target_field IN ('model', 'name', 'code')),
    created_at      TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
);

CREATE UNIQUE INDEX idx_semantic_source ON semantic_mappings(source_column);
```

### 字段说明

| 字段 | 类型 | 说明 |
| ------ | ------ | ------ |
| `id` | INTEGER | 自增主键 |
| `source_column` | TEXT | 源表中的列名（如"产品编号"） |
| `target_field` | TEXT | 映射到的目标字段（`model`/`name`/`code`） |
| `created_at` | TEXT | 添加时间 |

### 说明

- `target_field` 限定为 `model` / `name` / `code` 三个值
- `source_column` 唯一，避免重复映射
- 初始数据由用户首次匹配确认时填充
- 查询时联合内置关键词列表一起匹配

## 4. `column_config` — 列配置表

### DDL

```sql
CREATE TABLE IF NOT EXISTS column_config (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    field       TEXT    NOT NULL UNIQUE,
    label       TEXT    NOT NULL,
    width       INTEGER NOT NULL DEFAULT 120,
    visible     INTEGER NOT NULL DEFAULT 1,
    sort_order  INTEGER NOT NULL DEFAULT 0
);
```

### 字段说明

| 字段 | 类型 | 说明 |
| ------ | ------ | ------ |
| `id` | INTEGER | 自增主键 |
| `field` | TEXT | 数据库实际字段名（如 `model`, `name`, `code`） |
| `label` | TEXT | 用户自定义显示名称（如"产品型号"） |
| `width` | INTEGER | 显示宽度（像素） |
| `visible` | INTEGER | 是否显示: 1=显示, 0=隐藏 |
| `sort_order` | INTEGER | 显示顺序，升序排列 |

### 默认数据

```sql
INSERT INTO column_config (field, label, width, visible, sort_order) VALUES
    ('id',       '序号',     60,  1, 1),
    ('model',    '型号',     150, 1, 2),
    ('name',     '品名',     200, 1, 3),
    ('code',     '69码',     180, 1, 4),
    ('source',   '数据来源',  150, 1, 5),
    ('remark',   '备注',     200, 1, 6),
    ('created_at', '导入时间', 160, 1, 7),
    ('updated_at', '更新时间', 160, 0, 8);
```

## 6. 重要 SQL 查询

### 6.1 分页查询（含搜索）

```sql
SELECT * FROM products
WHERE (model LIKE '%关键词%' OR name LIKE '%关键词%' OR code LIKE '%关键词%')
ORDER BY id ASC
LIMIT :page_size OFFSET (:page - 1) * :page_size;
```

### 6.2 检测重复项

```sql
SELECT code, COUNT(*) as cnt
FROM products
GROUP BY code
HAVING cnt > 1;
```

### 6.3 获取重复完整记录

```sql
SELECT * FROM products
WHERE code IN (
    SELECT code FROM products
    GROUP BY code
    HAVING COUNT(*) > 1
)
ORDER BY code, id;
```

### 6.4 一键去重（保留 id 最小的）

```sql
DELETE FROM products
WHERE id NOT IN (
    SELECT MIN(id) FROM products GROUP BY code
);
```

### 6.5 语义匹配查询

```sql
SELECT source_column, target_field
FROM semantic_mappings
WHERE source_column IN (:列名列表) OR source_column LIKE '%' || :列名 || '%';
```
